# RF Link 无频谱主屏与频谱设置 v3

用户确认采用 `artifacts/rf-link-ui-design/no-spectrum-v3.png` 六状态效果稿，并要求在设置保留频谱开关。本文件补充并替代 [v2设计](2026-11-01-rf-link-ui-v2-design.md) 的主屏频谱及设置菜单规则；主题、音量、手机管理、通话历史和实体按键规则继续沿用 v2。效果稿是设计基准；真实LVGL预览位于 `artifacts/rf-link-handmic-preview/`，两者均不等于真机截图或听感验收。

## 主屏

默认关闭频谱。沿用黑底、四套主题、服务器及电量顶栏，移除频谱后重新组织信息，不保留空频谱框，不添加持续动画。

- 收听：呼号位于113px处，提供72px高区域。可容纳的大呼号使用32px字体；斜杠后缀可在斜杠后换行，超长呼号使用小字号完整呈现。183px分隔线下展示距离及网格。两者都缺失时显示“电台位置 / 暂无位置信息”；单项缺失显示 `--`，不会把未知距离显示为零。
- 讲话：保留“讲话中”标记与呼号，原右上计时取消；“本次讲话”下以32px显示 `MM:SS`，只在秒数改变时更新。底部保留“松开 OK 结束”。
- 收听/讲话：上一位固定在底部提示条，仅在已有通话历史且没有更高优先级提示时显示；不会与正文重复。
- 守听：保留本机呼号及最近三位；长呼号按实际高度排版，完整历史仍通过设置进入。
- 手机断开或服务器离线：顶栏显示“服务器未连接”，正文显示恢复引导，清除上个服务器/讲话人/本机呼号等旧业务身份。短暂重连与长期等待沿用v2时限和提示。

开启频谱后保留原v2收听/讲话布局，供同条件对照。主题页预览遵循当前开关：开启显示静态样例频谱，关闭显示最近通话分隔区域。

## 设置与保存

设置顺序为“最近通话、电台资料、音量、手机连接、主题、频谱、返回”。频谱项显示“频谱 开启/关闭”；共七项，每屏五行，选中第六/七项时窗口向下移动，底部操作提示固定，不溢出屏幕。

频谱项短按OK切换并立即保存，停留当前项。只有保存成功才改变生效值；失败保留原值，显示两秒“频谱未保存 / 请再试一次”。缺失保存回调按失败处理。启动缺省关闭，由持久化层通过 `hm_product_load_spectrum()` 载入已保存值，该函数不触发写入。不新增BLE命令或独立页面。

非主屏OK长按800ms返回、返回主屏后先松开再允许PTT、讲话及待发言时禁止设置入口等v2保护继续保留。切换开关不会自行发言、重连或清除手机绑定。

## 刷新与验收边界

UI保持58个固定LVGL对象。布局、开关或主题变化触发完整布局更新；活动通话的业务数据未变时走快速路径。关闭模式不触碰频谱对象；静态页和守听页在历史年龄、提示及重连边界未变化时不更新布局；开启模式仅在频谱/峰值数组改变时重绘；讲话计时仅按秒更新。音频分析/FFT停止和重置由音频层按同一设置执行，不能只靠UI隐藏。

产品测试覆盖缺省/载入不写、双向切换、保存失败/回调缺失、菜单边界、长按返回和PTT防误触。真实LVGL预览覆盖两模式、四主题、全页面、菜单逐项滚动、长呼号、缺失位置、离线身份清理及150帧固定对象更新，并检查字形与屏幕边界。固件构建、工具测试、真机显示、开关断电持久化和真实音频对照必须分别报告；预览成功不代表设备音频卡顿已解决。
