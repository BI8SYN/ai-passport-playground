# RF Link 产品界面与交互设计 v2

2026-11-02：主屏默认无频谱、可保存频谱开关及七项滚动菜单已由[v3补充设计](2026-11-02-rf-link-ui-v3-design.md)替代；其余交互仍遵循本文件。

用户已认可黑底荧光绿、电台仪表、真实音频频谱及最近通话效果稿，并要求以此为基准完善设计文件，覆盖音量、配对管理和多套颜色主题。本文件替代此前按讨论顺序追加的草案，是UI与交互的统一设计入口。

已确认的视觉基准：`artifacts/rf-link-ui-design/history-phosphor.png`。新增管理页效果稿：`artifacts/rf-link-ui-design/settings-phosphor.png`；四主题对照：`artifacts/rf-link-ui-design/theme-options.png`。图片为静态设计稿，不是设备运行截图；v2现已实现并按用户授权烧录；验证边界见[v2验证记录](../../development/rf-link-handmic-ui-v2-validation-2026-11-01.md)。静态效果稿仍不等于实机照片。

四套主题的具体颜色、菜单顺序、持久化与细节行为是本次补齐的默认设计，不表示用户逐字段确认。固件当前仍为首版UI。

## 1. 产品原则与边界

- 产品名称统一为 **RF Link**；广播名使用`RF Link · XXXX`区分设备，XXXX来自已有设备标识后四位。App扫描显示名可改，正式服务UUID不改。
- 240×320屏幕、三个实体键；用户应先看懂能否通话、谁在讲话，再看距离和声音变化。
- 主屏不放A/B频率，使用音频频谱。频率资料保留在电台资料，BLE资料字段不删除。
- App负责网络、身份、证书和网络音频编解码；设备不增加独立联网、账号、地图或证书管理页面。
- 用户文案不出现MTU、PCM、LESC、bond、订阅、认证、话权等内部术语。串口保留工程诊断。
- 对比过通话优先与电台仪表，用户选择电台仪表；浅绿色液晶底被荧光绿黑底取代。最终采用固定主信息位置、按场景切换辅助区域的方式，避免全部数据长期挤在主屏。

## 2. 页面结构与覆盖清单

| 页面 | 入口 | 必须覆盖的状态 | 离开方式 |
| --- | --- | --- | --- |
| 启动恢复 | 开机 | 读取设置、首次使用、已保存手机、设置读取失败 | 自动进入连接引导或主屏；故障明确提示 |
| 主屏 | 启动/返回/连接成功 | 守听、等待发言、收听、讲话、静音、短时断连、手机未连接、服务器未就绪、发言拒绝、达到时限、音频故障 | 未请求/未发送时长按上进入设置 |
| 设置 | 主屏长按上 | 最近通话、电台资料、音量、手机连接、主题、返回 | 选择返回或长按OK回主屏 |
| 最近通话 | 设置 | 0–5位、更新时间、长呼号、无记录 | OK回主屏 |
| 电台资料 | 设置 | 当前讲话人、无当前讲话人、完整/缺失/过期资料、长文字、多页 | 上下翻页，OK回主屏 |
| 音量 | 设置 | 0–100、静音、实时调整、保存成功/失败 | OK保存回设置；长按OK取消回主屏 |
| 手机连接 | 设置 | 未保存手机、已保存未连接、已连接 | 上下选择操作/返回，OK确认 |
| 连接引导 | 首次使用/手机连接 | 尚未开放连接、窗口60秒、等待手机、六位口令、连接处理中、成功、超时、失败、取消 | OK开始/重试，下键取消/返回 |
| 更换手机确认 | 手机连接 | 原手机将断开、取消、删除失败 | 上下选继续/取消，OK确认 |
| 移除手机确认 | 手机连接 | 断开并移除、取消、删除失败 | 上下选移除/取消，OK确认 |
| 主题 | 设置 | 四套配色、即时预览、保存/取消、保存失败 | 上下预览，OK保存回设置；长按OK取消回主屏 |
| 短提示/浮层 | 按键/设置/连接事件 | 音量、静音、保存失败、操作结果、发言状态 | 定时消退或状态恢复 |

没有独立“技术状态页”和调试菜单。固件版本、完整设备名称与当前服务器完整名可放在手机连接页的只读信息分页；不增加首层“关于”入口。

## 3. 主屏排布

- 顶栏约0–34px：RF Link、电池图标和百分比。未知电量显示空电池轮廓与短横线，不伪造百分比。
- 服务器约35–70px：单行名称，长名称省略，详情可看完整。
- 状态/呼号约82–154px：状态小一级，当前呼号大一级。守听显示本机；收听显示讲话人；讲话显示本机。
- 中区约175–220px：收发频谱；守听切换为最近通话，不画无意义的频谱基线。
- 收听辅助区约232–274px：距离突出、网格小字。约值保留“约”；无有效距离显示短横线，不当成0。
- 底部约282–310px：通话时显示上一位；守听时为按键提示。通话中无历史则省略该行，不显示“上一位—”。

守听时中下区显示“最近通话”及最多3位；没有记录显示“还没有通话记录”。频谱、记录行、距离和按键提示按场景互斥，不叠加塞入同一区域。主屏呼号优先单行，超宽先缩至最低可读字号，再在固定区域内最多两行显示，不省略/滚动；频谱和下方资料随两行模式缩减。底部上一位若连最小字号也放不下，整行隐藏，完整呼号保留在最近通话。主屏和列表须用24字符呼号实际预览。

本机呼号只出现一次。音量不常驻，音量0时保留小型“静音”标识。

### 收发与异常

- 讲话：“讲话中”反白状态块和已发送时长；颜色主题变化也保留反白，不能仅靠颜色区别收听。
- 等待发言：“正在连接通话 / 请稍候”；无发送频谱和计时，底部“松开OK取消”。许可到达后才进入讲话。
- 断连：实际音频立即停止。前约2秒显示“正在连接手机”，之后显示“等待手机 / 打开手机App / 连接RF Link”；不展示旧讲话人/距离。
- 手机已连、服务器未就绪：“暂时无法讲话 / 请在App中连接服务器”。已保存服务器名可作为次要上下文，不能呈现为仍在线。
- 严重音频故障：“声音暂不可用 / 请重启设备”，仍允许查看设置/更换主题，但不能进入可讲话状态。
- 连接恢复时OK仍按住，必须先松开，不自动开始发送。

## 4. 最近通话

- RAM内最多保留5个不同讲话人，以收到有效语音为依据；仅有讲话人通知而未收到语音，不形成记录。
- 同一身份再次讲话更新并置顶；使用当前服务器内的UID与完整呼号关联，不能把同呼号不同UID静默合并。
- 守听显示最近3位；当前收听时“上一位”排除当前正在讲话的人，显示此前最新一位。本人讲话不写入接收历史。
- 历史只显示呼号及最后一次收到语音的相对时间，不携带旧位置/距离。小于1分钟为“刚刚”，之后“N分钟前”，满1小时为“N小时前”。本地单调时钟计时，不依赖手机校时。
- 更换服务器context、结束BLE会话、重启清空；不写Flash，不记录语音，不跨服务器混合显示。
- 列表只读，无选择、呼叫、播放录音等隐含功能。长呼号优先缩小至可读字号，仍不够则完整显示两行并相应减少当前页条数，上下翻页；不得截断为另一个呼号。

## 5. 音频频谱

16根频谱柱，使用实际PCM频带能量；收听来自播放音频，讲话来自被许可发送的麦克风音频。快起慢落，短暂峰值保持，不使用随机跳动。静音收听显示静音标识，频谱随实际静音后的播放信号回落。

15–20fps为实现目标，需真机测量。音频/PTT优先于分析和绘图；只局部更新柱形，不按帧重建整页；分析窗口/快照有界、只保留最新结果，停流/断连/换人清除旧峰值。光晕为轻量静态边缘效果，不做扫描线、闪烁、噪点和跨页残影。

## 6. 设置与按键一致性

设置顺序：**最近通话、电台资料、音量、手机连接、主题、返回**。一屏最多6项；选中项反白，主题不改变选中语义。

| 场景 | 上/下短按 | OK短按 | 长按 |
| --- | --- | --- | --- |
| 主屏 | 音量±5 | 按住请求讲话，松开结束 | 未请求/未发送时长按上500ms进设置；不先增音量 |
| 设置/普通菜单 | 选择，边界停住 | 进入选中项 | OK长按800ms回主屏 |
| 最近通话/电台资料 | 翻页；单页不动作 | 返回主屏 | OK长按800ms回主屏 |
| 音量 | ±5，实时生效 | 保存并回设置 | 持续按上下可连调；OK长按取消改动回主屏 |
| 主题 | 切换预览 | 保存并回设置 | OK长按取消预览回主屏 |
| 连接引导 | 下键取消，上键不动作 | 开始/超时重试 | OK长按回主屏，关闭未完成窗口 |
| 破坏性确认 | 在继续/取消中选择 | 执行所选操作 | OK长按取消回主屏 |

确认页默认选中“取消”。显示两行明确操作，不使用“OK直接删除、上下取消”的隐含规则。设置中的OK短按在松开后执行；识别为长按时不再执行短按。主屏PTT使用PRESS/RELEASE，不等待CLICK。

所有非主屏页面都不能用OK触发发言；返回主屏时仍按住OK，需松开后下一次按下才可发言。收听时也允许长按上进设置，音频继续播放；仅等待发言、讲话及OK尚未释放时禁止进入。上下短按仍可调音量，识别长按后消费本次短按。设置中收到声音继续播放，以小型“收听中·呼号”提示替换普通页头辅助行，不抢走正在编辑的页面；要讲话先回主屏。设置不自动超时保存或删除绑定。

## 7. 音量设置

标题“音量”，大号数值、20格音量条，0–100，每次5。0显示“静音”；默认90，保留现有已保存值。

进入页前结算已有快捷调节保存，再以最终保存值作为取消基线；结算失败先回滚提示，再进入编辑。进入页记录原值；调整即时影响播放但不连续写Flash。OK持久保存后返回，长按OK取消并恢复原值。保存失败恢复原值并显示“音量未保存 / 请再试一次”，仍停留本页；允许继续修改和重试。

主屏快捷调节使用同一音量模型，1.5秒浮层；一串连续操作在结束约500ms后保存一次，失败回滚到最后保存值并提示。App音量命令可用但需串行化：音量编辑页打开时设备对远程`volume.set`返回`busy`、不改当前值，App按明确失败处理而非认为成功；不要求新增BLE操作。`busy`已在1.0合同内；此处补充占用场景，需在App说明中记录。快捷音量的延迟保存、本地编辑及App命令共用串行事务队列，旧延迟写入不能覆盖后到的App值；存在待保存快捷操作时先结算或向App返回busy。页面正常收音但不自动播放测试音；避免突然发声。

## 8. 手机连接与配对管理

单手机绑定、单连接维持不变，不引入多手机切换名单。

| 状态 | 显示 | 可选操作 |
| --- | --- | --- |
| 尚未保存手机 | 尚未连接手机；RF Link · XXXX | 连接手机、设备信息、返回 |
| 已保存，当前未连 | 等待手机；靠近手机并打开App | 更换手机、移除手机、设备信息、返回 |
| 已连接 | 手机已连接 | 更换手机、移除手机、设备信息、返回 |

系统未提供真实手机名称时不捏造型号或机主名称；设备为BLE外设，不放一个实际上不能主动连接手机的“立即重连”按钮。

- 首次开机显示“连接手机 / 在App中添加设备”，OK开始60秒窗口，下键返回未连接主屏。没有本机操作不自动开放配对。
- 开放后显示广播名和剩余时间；手机真正请求口令后才显示“请在手机输入”及六位数字，保留前导零。
- 系统绑定成功但业务尚未就绪时显示“正在连接”，三项必要订阅和HELLO完成后才提示“已连接”并进入主屏。窗口结束后尚未业务就绪进入等待手机，不重新删除有效绑定。
- 超时：“未连接到手机 / OK重试”；拒绝或失败：“未能连接 / 请重试”。若检测到旧配对不一致，再提示“请在手机蓝牙设置中忽略RF Link后重试”，不把此操作当所有错误的通用处理。
- 更换手机确认：“更换手机？ / 原手机将断开”，选项“继续”“取消”。继续后停流、断开、清旧绑定；删除成功才开放新窗口。失败不声称已移除，不自动擦除整个NVS。
- 移除手机确认：“移除手机？ / 下次使用需要重新连接”，选项“移除”“取消”。成功断开并清绑定，回到未连接状态，不自动开放窗口。
- 下键取消、长按OK取消和超时使用同一提交边界：系统绑定完成前关闭窗口并断开未完成连接；系统绑定完成后保留有效绑定，显示“已保存手机 / 等待连接”，不能误报未配对或引导再次创建绑定。普通断线不删除绑定。若更换确认已执行，之后取消新窗口不恢复已删除的旧绑定，取消前后的影响必须一致。

## 9. 多主题

四套默认设计如下，全部黑底、统一布局、统一字号与同一套状态语义：

| 主题名 | 稳定ID | 背景 | 主文字/频谱 | 辅助文字 | 细线 |
| --- | --- | --- | --- | --- | --- |
| 荧光绿（默认） | phosphor_green | #020604 | #5EFF7D | #389951 | #0E381A |
| 琥珀橙 | amber | #080502 | #FFBC59 | #BA873F | #4A3015 |
| 冰蓝 | ice_blue | #020609 | #65DBFF | #4299B5 | #103C4A |
| 柔白 | soft_white | #060707 | #DFEAE5 | #8D9D95 | #303E36 |

主文字对比度须实测；辅助文字也必须可读，不能只追求昏暗的荧光感。主题只改变颜色，不隐藏状态、不更换布局、不让红绿色成为判断条件。反白标签用主题主色底和背景色字；故障使用文字/图形提示，不能依赖某套主题独有的红色。

主题页上方显示当前预览名称，中间提供小型呼号/频谱/次要文字样例，下方“上下预览 / OK保存”。进入时定位已保存主题，上下立即预览整页；OK写入稳定ID，成功回设置；长按OK取消恢复原主题回主屏。保存失败恢复原主题，停留本页并提示“主题未保存 / 请再试一次”。只保存最终确认，不随每次预览写Flash。

重启恢复主题；缺失/未知ID回退荧光绿，不擦其他设置。首版NVS中无此键时只增新键，不迁移或重置音量/设备ID/手机绑定。主题无需App接口，不新增BLE控制命令。具体RGB值先作为设计令牌，真机对比度/黑位/光晕验收后可微调。

## 10. 电台资料与设备信息

电台资料第一页：当前讲话人、完整服务器名、网格、位置、距离和来源时效；第二页：A/B频率或RIG单频、型号、天线、高度。长文字可分行/分页，避免一屏多个滚动字段。高度表示天线高度，不冒充海拔。

没有当前讲话人显示“暂无通话资料”；资料部分缺失显示短横线。换人后即时替换或清除，不能拿上一位补空值；历史不保留可打开的旧位置详情。资料到期即时移除，位置已知但距离过期只清距离。

设备信息显示设备名称、固件版本、当前服务器完整名、手机连接状态；只读，不暴露密钥/证书/调试参数。

## 11. 文案及状态优先级

| 场景 | 文案 |
| --- | --- |
| 待机/接收/发送 | 守听 / 收听中 / 讲话中 |
| 等待许可 | 正在连接通话 / 请稍候 |
| 已知有人占用 | 有人正在讲话 / 松开后重试 |
| 原因未知的拒绝/超时 | 暂时无法讲话 / 松开后重试 |
| 达到讲话时限 | 本次讲话已结束 / 松开后可继续 |
| 必须重新按键 | 请先松开按键 |
| 服务器未就绪 | 暂时无法讲话 / 请在App中连接服务器 |
| 手机断开 | 等待手机 / 打开手机App / 连接RF Link |
| 音频故障 | 声音暂不可用 / 请重启设备 |
| 保存失败 | 音量未保存 / 主题未保存；请再试一次 |
| 配对数据操作失败 | 未能移除手机 / 请重试 |
| 未知电量/位置/距离 | 短横线，不使用虚构0值 |
