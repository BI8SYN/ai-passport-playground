# BLE 音频链路验证（2026-10-31）

## 范围

用户要求先用 Web 验证 Passport 作为 RF Link 专用 BLE 手咪的音频链路。本轮是可丢弃的实验增量，不改变已接受的独立联网 ADR，不实现生产身份、iOS 后台或正式电台功能。

在 `ble-signer-lab` 中追加独立音频特征，保留原签名协议和 NVS。网页入口 `http://localhost:8765/audio.html`，沿用本机静态服务器。设备控制、音频收发与状态特征分别为服务 `3fc10001-8b80-4f3a-9b22-4a4700000001` 下 UUID 后缀 5、6、7、8。

## 协议与指标

- PCM：8000 Hz、16 bit little endian、单声道，10 ms/80 samples，净负载 128 kbps/方向。
- 数据帧：uint32 LE 序号、uint16 LE 采样数、uint16 LE 魔数 `0xa001`，随后 PCM；标准帧共 168 bytes。要求协商 ATT MTU 至少 171；设备偏好 247。
- 模式：0 停止，1 设备麦克风通知到 Web，2 Web 无响应写入到设备扬声器，3 数据原样返回。模式由一个字节控制，采用有响应写。
- 原样返回使用确定性 PCM，每帧比较全部采样并统计往返耗时、缺帧、损坏和重复。该指标不包含 I2S/声学延迟。
- 扬声器接收队列最多 32 帧，初始预缓冲 6 帧/60 ms。统计溢出、欠载、通知失败、I2S 错误、序号跳变、PCM RMS 和空闲堆。下溢后重新预缓冲，断连停止并丢弃排队音频。
- 设备录音默认 10 秒，保留在网页内，可试听/下载 WAV。实时监听默认关闭，防止反馈。电脑麦克风可选，需用户授权，最长 30 秒。
- Web 定时和 GATT 调度不等于实时操作系统；本轮结果仅代表当前电脑 Chrome 链路，不代替真机 iOS 验收。

## 当前结论与待验收

当前桌面Chrome链路已经实际承载未压缩8kHz PCM，基础带宽无需依赖压缩编码才能验证。可继续研究RF Link专用BLE手咪，尚不能称产品音频验收通过。

待验收：设备真实发声/卡顿、录音人声听感、声学端到端延迟、长时间/距离/干扰条件、断连重连和PTT安全停止，以及真机iOS后台/锁屏。电脑麦克风→BLE设备实时流是可选入口，本轮未申请电脑麦克风权限、未执行。


## 输出音量修正

用户确认设备确实发声，但声音非常小。源码确认Codec设为55，同时测试正弦峰值2200/32767（约6.7%，-23.5dBFS）；不是以此症状推断BLE丢包。先只把Codec音量55改为90，保留正弦峰值与传输格式，便于单变量比较。

音量修正版构建与归档验证PASS：完整镜像SHA256 `1180a8c26fe3ac85cdcfadada48472668dcc5e5597fc0757cca494671dcd8e00`，匹配ELF SHA256 `295c7ae2933bf439f59fb36ab4e368d1b2e064a50ce6930776f39382f368c488`。仅改音量常量，不重复编写镜像实现的测试，原始完整gate与工具测试结果沿用前轮；本轮应用区写入与独立读回校验PASS，启动正常、bound=1、堆89960字节，Chrome重连MTU247并已重新播放同幅度测试音；响度效果待用户确认。写入/启动证据为 `artifacts/ble-audio-lab-validation/volume90-*`。


### 数字电平对照

用户反馈Codec90仍偏小。保持已刷入固件与Codec90不变，在Web新增测试音峰值选择2200/6000/12000/24000，默认12000；相对2200提高约14.7dB。编码后逐采样往返验证与峰值边界检查通过，12000峰值对应首帧RMS8536.8，未达到16位削波。此轮不重新构建或烧录固件。为保留原网页录音，另开音频测试页进行对照。

12000峰值真机复测：500帧/80000字节全部接收，设备播放PCM末帧RMS8573（原2200峰值为1571），无I2S错误、无序号缺口，欠载计数2。数据证据见 `artifacts/ble-audio-lab-validation/peak12000-results.json`，实际听感仍待反馈；这验证数字电平确实送达设备，不证明Codec实际寄存器增益或声压。

网页保留的后续另一轮原样往返记录为中位163.7ms、P95 190.4ms、最大225.7ms，仍2000/2000零缺损。说明当前桌面Web往返耗时有明显轮次变化，不能把最初73.1ms视为稳定承诺。


### 用户试听确认

用户确认：Codec90、测试正弦峰值12000时“明显变响，已合适”。因此将该组合作为后续播放试听基准；默认Web峰值已为12000，固件维持音量90，不再追加烧录。这个结果支持低测试PCM电平是此前低响度的重要因素，不替代实际语音响度、失真与动态范围验收，不应直接把真实语音一律放大5.45倍。
