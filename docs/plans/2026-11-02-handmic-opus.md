# RF Link Opus 压力试验版计划

用户要求实现Opus以测试设备压力。保留PCM/IMA，新增协议1.2的format=3：8kHz单声道、20ms、16kbps CBR，原始Opus包40字节，BLE完整包56字节。不使用Ogg、自定界长度头、DTX或FEC。

1. 固定乐鑫esp_audio_codec 2.4.0依赖，使用其C3实现。半双工共用一个按方向创建的实例，不同时保留编码器和解码器。编解码不得在BLE回调或core互斥锁内运行。
2. 增加可选能力、时钟/信用复用20ms模式、长度/TOC拒收。模拟器仅在实际拥有可用Opus实现时声明能力，避免误宣告。回归PCM/IMA与新协商。
3. 设备接收队列保存编码帧，在播放任务解码；采集任务在锁外编码，重新核对sid/stream/generation/按键后提交。编解码失败结束当前流，保留其他模式重协商路径。
4. 提供codec.get压力统计：分方向帧数、平均/最大耗时、20ms预算超限、错误/分配失败、当前及最低堆和任务栈余量。固件构建、主机回归及文档向量通过后归档；真机数值仅在获准烧录后报告。

不预先宣称C3可实时双向运行；尤其编码器内存不足时应正常拒绝/结束流，不能让设备崩溃。已有SSH设备目前为双OTA，后续写入须重新核对启动槽，不使用0x10000。
