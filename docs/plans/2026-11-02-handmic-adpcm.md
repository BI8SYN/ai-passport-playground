# RF Link IMA-ADPCM 实施计划

用户已确认实施此前推荐的8kHz、单声道、4bit、独立20ms块，并补充App对接文档。本轮开发、测试和构建，不烧录。

1. 添加无动态分配的独立IMA块编解码，明确160采样、84字节块、低半字节优先、首采样预测值和每块索引。先添加已知向量及非法块测试，确认缺失实现失败。
2. 增加协议1.1协商format=2，保持1.0/format=1兼容。序号和信用按协商帧递增；20ms下高水位6帧、裁剪至3帧，起播60ms仅一次。验证混格式拒收、MTU、信用、重复、超时、PTT释放。
3. 正式音频收发使用协商帧长，保持界面频谱覆盖完整PCM；BLE收发长度支持100/176字节。Web模拟器同步核心/原始PCM解码与帧长，避免新能力被错误宣告。
4. 增加App可执行参考编解码、公开向量及对接指南，描述协商、字节布局、时钟和回退；执行本地测试、模拟器测试、正式构建和完整门禁，归档精确镜像/ELF身份。

重点检查：IMA与Apple ima4不混用；末尾padding与非法index；丢包不传播状态；新HELLO/松键不泄漏旧音频；20ms帧不沿用10ms的队列时间预算；PCM老客户端保持可用。
