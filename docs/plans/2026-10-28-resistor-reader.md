# 色环电阻读取器实施计划

用户要求先提交合并环境分支，再开发首款独立固件；设备已连接，仅授权只读发现，烧录待明确确认。

## 产品与交互

离线 4/5/6 环读取器，按 Vishay 文档 20143 的色码表计算：4 环两位数字，5/6 环三位数字；倍率包括金/银小数倍率；显示阻值、容差范围，6 环额外显示温度系数。首位禁黑；容差仅棕红绿蓝紫灰金银；温度系数仅表中定义的棕红橙黄蓝紫。默认黄紫红金，4.7 kΩ ±5%。

上下键改变当前项，确定键循环选择环数及各环，长按确定切换4/5/6环。忽略 PRESS/RELEASE，DOUBLE等价两次短按；环数变化保留各角色颜色，新增第三位默认为黑。状态不持久化，不初始化网络或音频。

独立中文 LVGL 界面：顶部标题和电量、环数选项、中央带高亮当前色环的电阻图、较大阻值及容差、当前环角色/颜色、底部按键提示。复用 BSP，不复用测试菜单或 ui_pixel。中文字形逐项检查，并用同一 UI 源码做 240×320 无硬件渲染预览。
