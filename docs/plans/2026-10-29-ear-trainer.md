# 离线练耳固件实施计划

用户已接受五类核心离线训练、自主 UI、本地成绩，设备已接入并要求开始实施。基于已确认的可行性研究，采用独立 firmware/ear-trainer，复用 BSP；不实现跟唱识别、联网或发布。

1. 纯 C 模型与音源：音程三种播放、和弦性质/四步进行、四音阶、单音难度池、节奏示范/静音跟拍；先写模型/合成与计分测试，再实现。PCM 固定16k，独立工作任务；音高与削波用离线数据验证。
2. 新工程/容器构建入口及中文字体，独立 LVGL 界面。上下键移动、确定松手提交、长按返回并抑制释放；节奏确定按下计时。配置与按题型统计在本地保存。
3. 原生渲染真实 UI、字体检查、完整上游门禁与产品构建/打包验证，代码审查。所有依赖在容器，归档内容寻址。
4. 对绑定端口使用精确已校验产物进行本次设备测试；分段更新保持兼容 NVS，不全片擦除。记录启动日志。听感、屏幕、实体操作需用户观察，不把烧录成功等同于验收。

文件职责：ear_model.[ch] 乐理/出题/答题/节奏计分；ear_synth.[ch] PCM 音源；ear_ui.[ch] 自主布局；main.c 任务/音频/按键/持久化；tests/test_model.c 主机验收；README.md 使用方法与边界。
