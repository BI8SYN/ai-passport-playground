# 0003：RF Link Passport 首版改为纯 BLE 手咪配件

日期：2026-10-31。替代 [ADR 0002](0002-rf-link-independent-networking.md) 的首版产品方向。

## 已确认决定

用户完成 Web BLE 音频试听后，明确选择：

- Passport 是纯 BLE 手咪配件，使用 App 的网络身份。
- 首版 BLE 音频固定为 8 kHz、16 位、有符号小端单声道 PCM，预留后续编码扩展。
- 手机负责网络、证书/私钥、授权检查、语音编解码及业务状态；Passport负责麦克风、扬声器、PTT、显示和本地音量。
- 本角色没有独立网络客户端身份，不登记设备业务证书，不使用 BLE 远程签名。此前“每个独立网络终端独立证书”的原则仍适用于独立网络终端。
- 保留正常用户单设备单手机绑定目标，不追求抵抗持有设备者主动克隆；不写 eFuse 或永久锁机。

## 后果

不需要在手咪上配 Wi-Fi 或实现 MQTT/TLS/RAW/CA/CRL。App 需增加独立 BLE 音频适配器，不能直接把设备当作系统蓝牙耳机。手机锁屏/后台是否满足产品要求仍需 iOS 真机验证。

Web 原型证明了当前桌面条件下的 PCM 数据传输与用户试听可行，不证明生产协议、SMP 配对、PTT 安全、长时间稳定性或手机后台已实现。

## 协议定稿与实施

用户于2026-11-01确认按此方案定稿并开发。正式[BLE协议1.0](../spec/rf-link-handmic/protocol-v1.md)、App接入、资料合同与配对交互共同生效。独立应用位于 `firmware/rf-link-handmic`；旧实验保留作为历史证据，不冒充正式协议实现。产品真机验证须另记结果。
