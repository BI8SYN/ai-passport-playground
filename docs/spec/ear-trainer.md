# 听见音乐：产品设计

一个无需配网的随身练耳工具。通过听题、选择、纠错和重复练习，训练音高关系、和声与节奏感。界面、交互、乐理模型和合成音源分别维护，产品源码位于 `firmware/ear-trainer/`。

## 已实现功能

| 训练 | 内容 |
| --- | --- |
| 音程听辨 | 小二度到大九度，上行/下行/同时播放，固定或随机根音 |
| 和弦训练 | 十种单和弦性质、四步调内进行、分解后完整和弦试听 |
| 音阶听辨 | 大调、自然小调、和声小调、上行旋律小调 |
| 单音识别 | C4–B5题池、自选音符、六轮阶梯挑战 |
| 节奏挑战 | 自制匀速/变化旋律，示范、四拍预备、八次静音打点、偏差反馈 |

提供难度、速度、题量与自选题池；每题两次机会，首答和最终准确率分开统计。设置、累计成绩及薄弱项保存在本机。默认音量90，可在0–100调整。

## 三键交互

短按上下移动焦点，松手时执行，确定提交；长按确定约600ms结束或返回。长按上/下约400ms开始调节音量，持续每150ms调整5，松手不触发短按导航。音量实时生效并在松手后保存，0为数字静音。

节奏训练的确定键按下即记录时间，短按上键重听，下键结束；长按上下仍仅调整音量，不改变节奏时间线。

## 实现与边界

复用同一上游BSP；音频、界面、输入队列、NVS保存分离。乐理、计分、控制器和PCM音源可在主机测试，真实LVGL页面另做原生渲染和字形检查。完整固件按内容哈希归档，并验证分区与匹配ELF。主机测试、构建、写入校验和用户听感分别记录。

使用自制合成音色及旋律。反馈图为简化音符示意，准确音名以文本为准。节奏起点按音频缓冲估算，并提供时序偏置，不宣称实验室测量精度。当前不含跟唱、钢琴写出、独立识谱、联网或社交分享。
