# 配对与实体交互

> 界面v2基准已更新，页面、菜单、文案及三键交互以[产品设计v2](../../superpowers/specs/2026-11-01-rf-link-ui-v2-design.md)为准。下文记录已烧录首版的UI与不变的安全机制；“配对/重新配对”旧菜单名称和旧按键表不再用于v2实现。BLE安全/单绑定/60秒窗口合同不变，v2新增“手机连接”管理页，不代表固件已经更新。

首版为单手机、单连接BLE手咪。配对是系统BLE安全绑定，不申请设备网络证书；App继续使用自身网络身份。

未配对设备主屏按OK进入60秒配对窗口，也可空闲时长按上键打开菜单，选择“配对”。App扫描正式服务、连接，发起LE Secure Connections配对；设备显示六位口令，用户在手机系统界面输入。成功并完成必要订阅后进入待机。窗口关闭时拒绝新的配对，不以普通BLE连接成功代替认证。

日常使用时，已绑定手机自动扫描并重连，通过原bond恢复加密，再重新订阅、HELLO、同步状态。断连不删除绑定。配对页下键取消，超时后OK重新打开窗口。未认证时不开放音频与业务控制。

换手机时，在设备空闲主屏长按上键，选择“重新配对”。二次确认页OK才移除旧绑定并开启新窗口；上键或下键取消。解绑立即停流、断开旧连接，删除本机bond。若旧手机系统仍保留记录，在其蓝牙设置中“忽略此设备”再配对；仅在手机删除记录不会自动清除设备bond。设备不接受远程命令清除绑定。

| 页面 | 操作 | 行为 |
| --- | --- | --- |
| 主屏 | 按住OK／松开 | 请求发言／立即停止本地发言；App取得网络许可后才可开麦流 |
| 主屏 | 上／下短按 | 音量±5，0–100，保存成功后回报App |
| 主屏，空闲 | 长按上 | 停止本地活动并进入菜单 |
| 菜单 | 上／下／OK | 选择／确认：资料、配对、重新配对、返回 |
| 资料 | OK | 返回菜单 |
| 配对页 | 下／OK | 取消窗口／超时后重新打开 |
| 重配确认 | OK／上或下 | 移除旧绑定并配对／取消 |

主屏显示电量、BLE/网络状态、当前服务器、本机呼号、讲话人和距离。资料页显示TELE频率、RIG型号/网格/天线/高度及位置时效。App提供经过关联和校验的展示数据；位置未知显示空值，不显示虚假的零距离。GB2312中文字可显示，字库外字符以问号代替。

快速松开再按下必须创建新的按压和流代次；旧许可、旧语音帧不能恢复发送。BLE已交给控制器的帧无法撤回，App也必须在松键/停流后按stream_id丢弃迟到帧。真实电声停止时间、手机后台重连和系统配对界面须真机测量。
