# 听见音乐 / EAR LAB

一个无需配网的随身练耳工具。听音、作答、纠错，再针对薄弱项复练。界面围绕三键操作设计，使用本项目的合成音源。

## 上手

1. 开机后用上下键选训练项目，确定进入设置。默认音量90，可用长按上下调节；先保持入门难度，选“开始训练”。
2. 音程、和弦、音阶、单音训练中，听题后用短按上下键选择答案，短按确定提交。“重听题目”也在选择列表内，每题最多两次机会。
3. 答题后查看正确答案与音符示意、构成音；和弦可选分解试听：逐个播放构成音后，再播放一次完整和弦；进行中的每个和弦都按这个顺序播放。和弦进行逐步填写四个级数，单音阶梯挑战逐轮扩大题池。
4. 节奏训练先听旋律和四拍预备，进入静音后按确定键打八次拍。结束查看偏早/偏晚图；上键重新听题，下键结束本轮。
5. 任何页面长按上键约0.4秒增大音量、长按下键减小音量；持续按住会每次调整5，范围0–100，0为静音，屏幕会显示音量条。调好后选择重听试听。普通训练长按确定约0.6秒结束或返回上层；结束后选再练或返回，成绩在本机保存。无需手机、电脑或网络参与日常使用。

## 训练范围

| 类别 | 内容 |
| --- | --- |
| 音程 | 小二度到大九度；上行、下行、同时；固定 C 或随机根音 |
| 和弦 | 大/小/减/增三和弦、属七/大七/小七、挂二/挂四/七挂四；四步调内三和弦进行；分解重听 |
| 音阶 | 大调、自然小调、和声小调、上行旋律小调 |
| 单音 | 入门三音、自然七音、C4–B5半音；自选题池；六轮阶梯挑战从2音增至7音 |
| 节奏 | 匀速与变化乐句；八拍静音复现；顺序对齐、漏击和逐拍偏差 |

短按上下的移动/重听/结束在松手时执行，没有额外单击等待；长按上下只调音量，不触发短按动作。音量实时生效，松手后保存；播放不中断，节奏时间线不重置。

设置提供三档难度、三档速度、5/10/20题或不限题、音量及自选题池（至少两项）。阶梯模式固定六轮并自动扩展题池。累计统计区分模式，显示首答/最终正确率及薄弱项；和弦进行每一步算一项，节奏每拍算一项。中途结束只统计已经完成的答题项。

反馈中的简化音符位置用于回顾，准确音名以显示的 C4/C#4 等文字为准；不是完整乐谱编辑器。音阶较长时文字仅显示前四音，全部八音可以重听。首版不含跟唱识别、钢琴写出或独立识谱训练、账号和分享功能。

## 构建与验证

```sh
./tools/dev test
./tools/dev build ear-trainer
./tools/dev preview ear-trainer
```

ESP-IDF 5.5.3、依赖与原生 LVGL 预览都在容器内运行。独立组件解包缓存由 Compose 管理；纯逻辑、PCM 合成器与控制器有主机测试。全量上游门禁使用 `./tools/dev gate`，与本产品构建分别记录。最终完整镜像、分段镜像及匹配 ELF 位于仓库忽略的 `artifacts/ear-trainer/<SHA256>/`，打包时检查8MB边界、分区、镜像及 ELF 身份。

## 声音与节奏限制

音源为16kHz单声道、多声部合成音色。整段按最高重叠声部数分配固定增益，保持单音响度和和弦余量。界面音量55对齐板级音频示例的Codec80档，高档位继续提高至100对应Codec100；0通过全零PCM实现真正静音。不是直接把百分比传给Codec的衰减曲线。默认音量为90；本轮从旧版升级会一次性将音量设为90，其他设置和成绩保留。此后重启保留手动调整的音量。音高/时长与混音峰值经过主机测试；小喇叭音区、听感与实际打点延迟需要真机观察。

节奏以音频时间线安排拍点，按下事件立即记录时间；不等待单击判定或界面刷新。当前使用 BSP 的 DMA 缓冲估算出声时间，不宣称实验室测量精度。默认以±80ms作为命中范围，偏差分数按绝对误差递减；设置的“时序偏置”可在 -150 至 +150ms 调整：总是偏晚时增加，总是偏早时减少。它修正稳定偏移，不能消除随机抖动。变化乐句与示范均由项目自制。

保存使用独立 NVS 命名空间 `ear-lab`，不自动擦除其他应用数据。当前分区与色环固件兼容；设备迭代优先使用已验证的应用镜像在0x10000分段更新以保留 NVS。完整镜像从0x0写入可能覆盖数据，需单独确认对应写入范围。不得整片擦除作为默认步骤。
