# 色环电阻读取器

AI Passport 上的离线色码计算器。屏幕绘制当前电阻，人工选择 4、5、6 环及各环颜色，即时显示阻值、容差和允许范围；6 环额外显示温度系数。默认黄、紫、红、金：4.7 kΩ ±5%，范围 4.465–4.935 kΩ。

## 操作

| 按键 | 行为 |
| --- | --- |
| 上 / 下短按 | 按下即修改当前项的下一个 / 上一个合法选项 |
| 确定短按 | 循环选择各色环及顶部环数选项 |
| 长按确定400ms | 选中上一环；松手不再前进 |
| 连按两次确定 | 前进两环，不等待双击判定 |

电阻采用两端鼓起、中间收腰的本体、曲面明暗、涂层高光、金属引脚及金银环反光；4环米黄色本体，5/6环蓝灰色本体。4/5环将末端容差环拉开距离，6环将末端温度系数环拉开距离；保留其正确的计算角色。这是示意图的视觉布局，不将间距视为色码含义或所有实物统一的间距规范。界面去掉左右/方向提示、环号排布和颜色名称；当前环仅在本体下方用青色短线标记，下方说明当前环的序号与作用。阻值与单位组合居中，环数采用紧凑选项。选中顶部环数后，上下键也可切换环数。切换保留数字、倍率、容差等角色的颜色；新增的第三位初始为黑，因此 4 环 4.7 kΩ 切为 5 环后是 47 kΩ。重启恢复默认值，不保存状态。电量不可用显示 `--%`。

## 色码与范围

按 [Vishay 色码表（文档 20143）](https://www.vishay.com/doc/?20143=)实现：4 环两位有效数字，5/6 环三位；数字黑到白，首位禁黑；倍率黑到白及金 ×0.1、银 ×0.01；容差棕1%、红2%、绿0.5%、蓝0.25%、紫0.1%、灰0.05%、金5%、银10%。6 环温度系数采用该表明确列出的棕100、红50、橙15、黄25、蓝10、紫5 ppm/K。

非法角色颜色不出现在循环选项中。阻值用整数保存到 0.01 Ω，显示自动选 Ω/kΩ/MΩ/GΩ，容差范围最多可用 TΩ；显示最多六位有效数字。最低 0.1 Ω，最高 999 GΩ。这是人工输入色码的读取器，不含摄像头识别或电气测阻功能。首版不启用网络、音频或自动休眠。

## 构建与检查

仓库根目录执行：

```sh
./tools/dev build resistor-reader
./tools/dev test
./tools/dev preview resistor-reader
```

主机不安装 ESP-IDF 或字体工具。`preview` 使用容器内原生 C 编译同一份 UI、字体、模型及锁定的 LVGL，生成 artifacts/resistor-reader-preview/{4,5,6}-band.png，检查字形、容差文案并运行500次状态更新。使用与设备相同的 32 KiB LVGL 堆；电阻图另用36,480字节静态RGB565缓冲区和240,864字节只读Flash资源，改颜色仅更新11×53贴片，改环数拷贝本体/色环，切换焦点或电量不重绘电阻；预览无法证明实际按键、电池、屏幕颜色或圆角表现。

`main/resistor_model.*` 是纯 C 模型；`main/resistor_ui.*` 是独立 UI；`main/main.c` 通过 BSP 读取按键、电量并初始化显示。按键回调只投递队列，LVGL 定时器在 UI 任务处理状态，不在按键回调中绘图或读取 I²C。

构建产物在 artifacts/resistor-reader/<完整镜像SHA256>/，含完整镜像、应用镜像、配套 ELF/MAP、bootloader、分区表、flash_args 和 manifest.json。验证工具检查 ESP32-C3、8 MB、镜像内容/地址/边界、分区和应用项目名、ELF SHA256。打包使用本地 tools/package_firmware.py，复用上游解析器；不修改上游固定产物名校验器。

可在容器中独立复核：

```sh
docker compose run --rm --no-deps -T sdk python3 tools/package_firmware.py verify \
  /workspace/artifacts/resistor-reader/<SHA256> --app resistor-reader
```

完整镜像从 0x0 开始，覆盖到应用末尾，包含分区表和中间填充区，可能重置 NVS/设置。构建命令不访问设备。烧录须在确认端口、精确镜像和数据影响后独立授权。

## 待真机验收

确认屏幕与预览一致；黄紫红金显示4.7 kΩ ±5%；逐环修改和首位/容差非法颜色跳过；切换4/5/6环；金银小数倍率；6环温度系数；短按、双击、长按后释放不产生额外动作；电量刷新。USB连接或编译通过不能替代上述验收。


## 低延迟输入与诊断

输入复用BSP原始PRESS/RELEASE事件，保留其ADC去抖；应用忽略延后的CLICK/DOUBLE/LONG事件。上下在稳定按下时响应，确定在短按松手时前进、按住400ms时后退一次。纯C输入状态机使用事件原始时间戳，支持连续快速按键和计时器回绕；长按后释放不会再前进。顶部环数选项纳入同一选择循环，上下编辑4/5/6环。

输入轮询5ms，LVGL刷新周期10ms，启用性能编译；UI按焦点/数值/容差/温度/电量变化分别更新，避免无变化文字重新排版。美术改为离线烘焙，见 [绘图资源](../../assets/resistor/README.md)，保持与原算法逐像素一致。没有修改上游BSP或LCD时钟。

`./tools/dev build resistor-reader --benchmark` 是显式诊断构建，使用独立构建目录并将来源mode记为benchmark；开机自动比较原浮点算法、快速全图、单环和UI刷新提交，完成后仍可操作。诊断期间会暂时显示测试状态，正常交付必须使用不带该选项的普通构建。普通构建不编译旧算法和基准代码。基准结果不是物理按键到屏幕光子的完整延迟，也不能代替用户手感验收。
